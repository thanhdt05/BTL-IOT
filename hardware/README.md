# Phần cứng — TV1 — TODO

Ghi BOM P0 một ESP32/DHT22/relay/quạt DC trước, pinout đúng bo/module, sơ đồ nối dây và ảnh/log thật. GPIO tham chiếu theo mục 3; xác minh phần cứng thực trước lắp.

Mục tiêu thử nghiệm chưa phải số đo. P0 mô tả đầu ra relay, không kết luận quạt quay/hỏng khi chưa có RPM. P1 monitor chỉ bổ sung sau P0.
